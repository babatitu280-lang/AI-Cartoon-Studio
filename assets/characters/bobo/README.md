# Bobo Character Assets

This folder stores Bobo's permanent 2D artwork.

Required assets:
- character_reference.png
- idle.png
- walk.png
- run.png
- jump.png
- expressions/

Design requirements:
- Preserve the approved original Bobo design.
- Maintain consistent proportions and colours.
- Use polished 2D cartoon artwork.
- Transparent backgrounds for character assets.
- No 3D artwork.
